Shows Chuck Norris and a random Chuck Norris fact on the build page and the job page, prints the fact to the build log and returns it as a String.

Call it in a post section so Chuck's mood reflects the final build result:

post {
    always {
        chuckNorris()
    }
}

To reuse the fact, assign the return value, for example def fact = chuckNorris() inside a script block. Calling the step more than once in a build replaces the earlier fact.
